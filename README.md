# MistbornSide

An unofficial, non-commercial fan game: a 2D sidescrolling retelling of Brandon Sanderson's original Mistborn trilogy, played as Vin, built in Godot 4.7.

- Start with `docs/DESIGN.md`: what kind of game this is and how Allomancy, combat, stealth, controls, missions and art are meant to work.
- `docs/research/` holds the book-sourced reference notes the design draws on.
- `CONTEXT.md` is the glossary: the words code, levels and docs use for the game's concepts.

## Project layout

| Folder | Holds |
|---|---|
| `scenes/` | Reusable scenes: characters (`scenes/player`, `scenes/enemies`), props, UI. A scene here is placed into levels, never run on its own. |
| `scripts/` | GDScript, grouped by system: `core` (autoloads, tuning, time), `player`, `allomancy`, `enemies`, `level`, `ui`, `fx`. One `class_name` per file, file named after the class in snake_case. |
| `levels/` | Playable levels, one folder each (`levels/greybox`, `levels/missions/...`), holding the level scene and anything only that level uses. |
| `art/` | Sprites, normal maps, tiles, shaders and textures. |
| `audio/` | Sound and music. |
| `data/` | Data-driven content: dialogue scenes, tuning presets. |
| `tests/` | Headless tests (`tests/unit/test_*.gd`) and their helpers. |
| `tools/` | Developer scripts: test runner, script check, input map generator. |
| `docs/` | Design, decisions, research, mission notes, playtest notes (`docs/playtests`), the Act 1 go or no-go (`docs/decisions`). |

## Running

Open the folder in Godot 4.7 and press F5: the title screen offers the vertical slice (mission 4, Eight Metals, then mission 9, Kredik Shaw), the settings, and the practice yard (the M0 grey-box rooftop course). Esc pauses, F1 opens the live tuning panel, F3 toggles the frame-rate readout.

Developer commands (they use the Flathub Godot by default; set `GODOT` to point elsewhere):

- `tools/check.sh` compiles every script and fails on parse or type errors.
- `tools/test.sh [filter]` runs the headless test suite, optionally only files whose name contains `filter`.
- `tools/export.sh` exports Linux and Windows builds into `build/` (needs the Godot 4.7 export templates).
- `tools/generate_audio.py` regenerates the placeholder sounds; `tools/export_sprites.gd` writes the procedural character sheets to `art/characters`.
- The input map is generated by `tools/setup_input_map.gd` from the tables in DESIGN.md section 7; edit it there and re-run it rather than editing `project.godot` by hand.
